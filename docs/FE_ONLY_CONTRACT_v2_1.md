# FE-only контракт (v2.1) — быстрые UI-правки по фидбеку

Цель: зафиксировать минимальные изменения **только фронтенда**. Backend трогаем только если станет критично (в этой итерации не требуется).

## Навигация (вкладки)
- Вкладки: **«Новая заявка»** и **«Заявки»**.
- Переключение реализовано на фронтенде, без роутинга.
- При переходе на «Заявки» фронтенд делает `GET /api/booking-requests` и рисует карточки.

## AI
- Кнопка/фича **AI-проверка удаляется полностью**.
- Вместо неё: кнопка **«Заполнить примером»** (или «Тестовые данные»).
- Нажатие заполняет форму случайными валидными значениями.

## Дата
- Используется лёгкий datepicker без тяжёлых зависимостей.
- Значение в поле хранится в формате **YYYY-MM-DD**.

## API (используем как есть)
- `GET /api/booking-requests` → `{ items: BookingRequest[] }`
- `GET /api/booking-requests/:id` → `{ item: BookingRequest }` или 404
- `POST /api/booking-requests` → создание
- `PUT /api/booking-requests/:id` → редактирование

## Ошибки
- Валидация: HTTP **422**
- Форма: `{ error: { code: "validation_failed", details: { fieldErrors: Record<string,string> }}}`

## UI/UX
- `select` («Длительность», «Формат») визуально одинаковы по ширине/стилю с `input`.
- Hover-эффект на кнопках: визуальная подсветка/поднятие.
